# AudioHub

把多台设备的声音混成一路，送进同一副蓝牙耳机。

蓝牙耳机支持多点连接，但同一时刻只会播出一路。AudioHub 让一台 Windows 机器充当混音中枢：
本机播放的声音、安卓手机的声音各自进入混音器，混好之后从你选的输出设备（通常是蓝牙耳机）播出。
手机与电脑之间走 **VBAN**（开放协议，UDP）——不需要数据线、不需要 root、不需要装驱动，
也不需要 Voicemeeter 之类的虚拟声卡。

> 代码、测试与文档在 AI 辅助下完成；需求、技术取舍与验收标准由作者把关。
> 无法自动验证的部分（听感、界面观感等）明确标注为未验证，不冒充已验证。

## 下载

去 [Releases](https://github.com/Xu2123456789/AudioHub/releases/latest) 下载，一共三个文件：

| 文件 | 大小 | 给谁 | 电脑上要先装什么 |
|---|---|---|---|
| `AudioHub-PC-self-contained.zip` | 约 67 MB | 不想折腾 | **什么都不用装**（运行时已打包） |
| `AudioHub-PC-framework-dependent.zip` | 约 0.8 MB | 只在自己电脑用、在意体积 | .NET 8 桌面运行时 |
| `AudioHub-Sender-<版本>.apk` | 约 9 MB | 安卓手机 | —— |

两个电脑包**功能完全一样**，区别只在要不要先装 .NET 运行时（缺了会有中文提示和下载链接，不会闪退）。
APK 是 debug 签名，安装时安卓会提示「未经验证的应用」——因为没上架应用商店，属正常。

## 安装与启动

1. 解压电脑包到任意文件夹（自包含版解压后约 160 MB）。
2. **首次**：双击一次 **`install-shortcut.bat`**，在开始菜单建一个 `AudioHub` 快捷方式（不建桌面图标）。
   以后按 Win 键输入 `AudioHub`、回车就能启动。
3. 首次再双击一次 **`allow-firewall.bat`** 并同意 UAC，放行两个入站端口：
   UDP **6980**（音频）与 UDP **6979**（自动发现）。只开 6980 的话，手机能连上但「查找电脑」找不到。
4. 之后每次用就搜 `AudioHub` 回车。控制窗口**会自己弹出来**，右下角同时留一个耳机图标
   （可能收在 `^` 箭头里）；关掉窗口后双击图标能再打开。
   窗口里能看当前输出设备、调每一路音源的音量、展开「手动连接」看手机要填的信息。
   **输出设备不能在窗口里切**，它跟随 Windows 的默认播放设备。要退出：右键托盘图标。

> 包里一共 7 个脚本文件。日常只用快捷方式（它指向 `start-audiohub.bat`）；
> `install-shortcut` 和 `allow-firewall` 各跑一次就不用管；`.ps1` 是它们的内部实现，不用手动运行。
> 不想建快捷方式也行：直接双击 `start-audiohub.bat`，效果一样。

## 手机连上来

1. 电脑上启动 AudioHub（按 Win 搜 `AudioHub` 回车，或双击 `start-audiohub.bat`）。
2. 手机打开 AudioHub → **「查找电脑」** → 点列表里那台电脑 →「开始发送」，同意录屏授权。
   这时还没输密钥，所以是**明文发送**：能听，但没有加密。
3. 想加密再配一次：电脑窗口**展开「手动连接」**（默认收起），点「配对密钥」右边的「显示」，
   把密钥抄到手机上输一次——之后它会记住。

找不到电脑还有三条路：**扫二维码**、**输六位短码**（这两个在电脑窗口的「手动连接」面板里），
或者手机展开 **「高级设置」** 手填 IP（地址抄电脑面板「本机地址」里带「（推荐）」的那个）。

> **加密要求手机知道「这是哪台电脑」**——派生密钥要用电脑身份，光有地址推不出来。
> 「查找电脑」选中、扫二维码都自带身份；短码和手填 IP 只给地址，点「开始发送」时手机会单播问电脑
> 一次（约 1 秒），问到了就能加密；问不到且填了密钥会被拦下并说明原因，不填密钥就走明文。
> 手机「链路」那一行会把这次的结论写出来，不会假装在加密。

## 连不上先看这几条

先双击 **`audiohub-verify.bat`**：它会列出本机 IP、防火墙规则、播放设备、配对密钥，
再试收 90 秒，一条命令拿到客观结论。它和托盘程序都要占 UDP 6980，跑之前先退出托盘。

- **「查找电脑」什么都找不到**：多半是路由器开了 AP 隔离（访客网络常见），广播被挡。
  换手机热点，或退回扫二维码 / 短码 / 手填 IP。
- **填了地址还是不通**：电脑插着网线又连着 Wi-Fi 时会有两个 IP，填了别的网段就不通。
- **声音不来、两边都不报错**：加密没对上（密钥、电脑身份、版本三者任一不一致都会这样）。
  看手机界面上「链路」那一行。
- **端口被占**：UDP 6980 被别的东西占着时收不到，先退出托盘程序再重开。
- **换过电脑、或删过 `%LOCALAPPDATA%\AudioHub\key.json`**：手机手里的旧密钥解不开新的，
  表现是「安静地连不上」，重新配对一次。

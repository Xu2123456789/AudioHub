# AudioHub PC 端使用说明

> 版本：AudioHub 1.0.0。本说明对应 `AudioHub-PC-self-contained.zip`（零安装）与 `AudioHub-PC-framework-dependent.zip`（需 .NET 8 桌面运行时）解压后的内容。
> 一句话：日常只点 `start-audiohub.bat`；排查只点 `audiohub-verify.bat`。

## 一、解压后你看到什么

发布包解压出来的根目录里，和"用"直接相关的只有 **3 个 `.bat` 脚本**，其余是程序本体（`AudioHub.App.exe` 等）和依赖，不用管：

| 脚本 | 干什么 | 什么时候用 |
|---|---|---|
| `start-audiohub.bat` | 启动托盘程序（日常） | **每次用都点这个** |
| `audiohub-verify.bat` | 一键自检 + 加密链路验证 + 引导手机 | 首次设置、换网络、连不上时 |
| `allow-firewall.bat` | 配置 Windows 防火墙放行 | 一般不用手动；`audiohub-verify.bat` 缺规则时会自动调它 |

> 手机端是单独的 `app-debug.apk`，不在这个包里（见第七节）。

## 二、脚本的精确路径

假设你把包解压到了 `D:\AudioHub\`（任意位置都行），三个脚本就在解压**根目录**，和 `AudioHub.App.exe` 同层：

- `D:\AudioHub\start-audiohub.bat`
- `D:\AudioHub\audiohub-verify.bat`
- `D:\AudioHub\allow-firewall.bat`

对应到本机源码/发布目录，两个版本各有一份（内容相同）：

- 自包含版：`<项目根目录>\dist-self-contained\` 根目录
- 框架依赖版：`<项目根目录>\dist\` 根目录

## 三、第一次怎么启动（日常用法）

1. 解压发布包到任意文件夹。
2. **双击 `start-audiohub.bat`**（路径见上）→ 右下角托盘出现耳机图标（可能在 `^` 箭头里）；双击图标可开控制窗口，能切输出端点、调音量。
3. 手机上装好 `app-debug.apk` → 打开 AudioHub → 「查找电脑」→ 配对（或明文直连）→「开始发送」。
4. 戴蓝牙耳机：**电脑声 + 手机声同时从耳机出来**。

> 框架依赖版若没装 .NET 8 桌面运行时，双击 `start-audiohub.bat` 会弹中文提示和官方下载链接，不会闪退。

## 四、怎么用 `audiohub-verify.bat`（验证 / 排查）

- 路径：解压根目录（见第二节）。
- 双击它，按屏幕提示走，它会**一次完成**：
  1. 显示本机 IP，并直接标出「手机请填这个」的那个地址（已滤掉 169.254 / 127 这类填了也通不了的地址）；
  2. 检查并**自动修复** UDP 6980 / 6979 防火墙规则（首次会弹 UAC，点"是"）；
  3. 列出播放设备（标 `*` 的是声音去向）；
  4. 显示**配对钥匙**（手机上输一次）；
  5. 列出手机端要填的每个参数（IP / 端口 / 流名称 / 密钥），并说明「手填 IP 只能明文」；
  6. 用真正的接收端跑 90 秒，每秒打印 `accepted`，同时应答手机的「查找电脑」。
- 判断标准：第 6 步 `accepted` 在涨 = 声音到了电脑；耳机里听到手机的声音 = 完全成功。
- 它**不会再播测试音**（早期版本有一步 440 Hz 自测，因为太吵已去掉）。想知道捕获通路是否正常，用命令行 `AudioHub.Cli.exe --selftest`。
- ⚠️ 跑 `audiohub-verify.bat` 时**不要**同时开 `start-audiohub.bat`——两者都占 UDP 6980 端口。验证完日常用，关掉 verify 再开 start-audiohub。

## 五、怎么用 `allow-firewall.bat`

- 路径：解压根目录。
- 一般不需要手动点：`audiohub-verify.bat` 检测到缺规则会自动弹 UAC 调它。
- 若想手动：双击它（会要管理员权限，UAC 点确认），一次配置永久生效。
- 它做两件事：①删掉所有旧的 AudioHub 规则（**包括"阻止"规则**；阻止规则优先级高于放行，不删就永远不通）；②新增 UDP 6980 与 UDP 6979 两条放行，**不再绑定到某个 exe 路径**——换版本（`dist` / `dist-self-contained`）或移动文件夹都不会失效。
- 范围：`remoteip=LocalSubnet`，只有同一 Wi-Fi / 热点内的设备能访问这两个端口，不暴露到公网。

## 六、常见问题

- **手机"查找电脑"找不到**：多半是路由器开了 AP 隔离 / 客户端隔离，广播被挡。先在手机手填电脑 IP（`audiohub-verify.bat` 第一步显示的 IPv4）；或关掉隔离。
- **声音不来、两边都不报错**：加密没对上（钥匙错 / 身份 UUID 错 / 版本不一致），去手机看「链路」那一行。
- **端口冲突**：6980 被占时验证会失败，先关掉托盘应用（`start-audiohub.bat`）再跑 `audiohub-verify.bat`。

## 七、手机端 APK

- 文件：`app-debug.apk`（debug 签名，安卓会提示"未验证应用"，正常）。
- 本地路径：`<项目根目录>\android\app\build\outputs\apk\debug\app-debug.apk`
- 若从资料库下载到的是 `AudioHub-Android-v1.0.0.bin`，把后缀改回 `.apk` 即可安装。

## 八、加密判据（最重要）

手机「链路」那一行必须显示 **已加密（AES-256-GCM）** 才算配对生效。
显示「明文，未加密」但声音照响——这是最危险的情况，别放过（同网的人可能往你耳机塞声音）。
